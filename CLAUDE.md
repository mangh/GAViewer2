# CLAUDE.md — Geometric Algebra Viewer

## Project Overview

This project implements a ***viewer*** for figures defined using ***geometric algebra (GA) expressions***. You can enter expressions *interactively from the keyboard* or *load them from files*. You can interact with the displayed figures (zoom in/out, rotate, view/turn off/remove their elements, etc.).

The starting point is [the GAViewer application source code](https://geometricalgebra.org/downloads/GAViewer-0.86.tar.gz) available on the [Geometric Algebra For Computer Science](https://geometricalgebra.org/index.html) website, extended with the source code of the following external components:

- [ANTLR2 parser generator](https://www.antlr2.org/download/antlr-2.7.7.tar.gz) to build the GA expression parser,
- [FLTK (Fast Light Tool Kit)](https://github.com/fltk/fltk), a cross-platform C++ GUI toolkit, to give the application a graphical interface,
- (optional) [sample figures](https://geometricalgebra.org/downloads/figures.zip) available on [GAViewer interactive book figures](https://geometricalgebra.org/figures.html) page.


The goal of the project is to:

- modernize/restructure the C++ source code (transition to C++20),
- replace geometric algebra generated by [Gaigen](http://sourceforge.net/projects/g25/) with that provided by [Garamon](https://github.com/mangh/garamon) fork,
- upgrade the Antlr2 parser to a newer version or replace it with another parser that's currently available.

## Testing

Headless regression tests (`viewer/test`): the `gaviewer_regress` harness links the same `gaviewer_core` static library as the GUI, runs each book figure (`FIG_x_y();`) with `gui_state == NULL`, resumes at every `suspend;`, and dumps per frame the console output plus every object (multivector coordinates and `mvInt` interpretation). The dump is compared with `viewer/test/golden/FIG_x_y.txt`: numbers within a relative tolerance (1e-6), everything else exactly.

```
ctest --test-dir build -j8 [-R FIG_2_2] [--output-on-failure]   # run
cmake --build build --target regress_update_golden              # regenerate golden files (only after an intended change)
```

- Failing test → actual output in `<build>/viewer/test/actual/FIG_x_y.txt`; diff it against the golden file.
- Run one figure by hand: `gaviewer_regress -I <figs-src> "FIG_2_2();"` (dump to stdout).
- Code reachable from console functions or GA-file commands must check `gui_state` for NULL (the harness has no GUI).
